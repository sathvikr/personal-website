[1] What if the particular memory games are just harder? Are games of type “memory” simply harder than games of type “visual”? If we made the visual games as “visually difficult” as the memory games are “memory difficult”, would we see a more evenly distributed histogram of geometric means?

[2] Why do we have to bucket demand thresholds based on difficulty from humans? Human intelligence evolved this way as a function of our environment and cognitive constraints. The same could be true for models. Does this just mean we have to design RL environments that force models to have better, e.g., “memory”?

[3] Biggest bottlenecks: memory, planning, and world modeling categories. An AI model might not treat these categories as separate though. Hard to say.

[4] As games demand more cognitive capabilities, performance drops. Models are best when they only focus on one cognitive ability (highest geometric mean). This suggests that the human-devised “ability buckets” actually are tied to performance.

[5] Humans wait for some time (maybe to build the world model) but after building the world model humans have a very high slope.

[6] Is the time thinking really a factor? Can we compare human thinking times with model thinking times one to one?

[7] Overall I think this is a good benchmark because

Shows human-vs-AI gaps. All games are extraordinarily simple, unlike ARC-AGI. Humans also have not seen significant training data related to these games. We have, however, had our training data form the cognitive abilities that help us win these games effortlessly. Hence, agent failures directly hint that models lag in certain core inductive biases.

Concrete and specific. Highlights deficiencies in specific cognitive capabilities (planning, memory, and world modeling). It is probably true that if these cognitive capabilities are improved, performance on productive real-world tasks will also improve drastically.

Hard to overfit. The goal of an infinite game benchmark makes overfitting on game-specific mechanics that aren’t inductive biases difficult. Hence, hill-climbing on the overall benchmark likely corresponds with hill-climbing on the core cognitive capabilities.

[8] Interested in how the Novel Games thesis fits into the AI game store.

[9] We also need robust ways to quantify failure. If a model achieves a poor score, how do we know it is because of, e.g., poor planning skills? The current approach is to see if other planning-based games also achieve low scores, which is correlation-based and thus fallible.
