Abstract. We present a series of six ablation experiments on an LLM-based agent playing ARC-3, a procedurally generated game requiring real-time discovery of hidden mechanics. We test four hypotheses about belief management, knowledge representation, prompt complexity, and plan length. Our findings show that structured knowledge tracking (KNOWN/UNKNOWN) reduces Level 1 solve time by 57% over hypothesis-confidence tracking, that domain-specific prompt content reliably degrades performance, and that the adaptation interval between planning cycles is a critical and under-appreciated parameter.

1. Introduction

LLM agents deployed in open-ended environments face a fundamental challenge: they must discover the rules of the world from scratch, without access to documentation or prior examples. In procedurally generated games, every instance presents novel mechanics, making memorization impossible and online learning essential.

The default behavior of long-context language models in sequential reasoning tasks is narrative lock-in: once a plausible explanation forms in the context window, inertial forces keep it there. The model commits to its first hypothesis and never explores alternatives. This is catastrophic in environments where the correct strategy can only be discovered through systematic experimentation.

We investigate what kinds of scaffolding structures help an LLM agent overcome this default. Our testbed is a single ARC-3 puzzle (ls20), which we hold fixed across all experiments to isolate the effect of architectural changes from task variance. Over six ablations, we test the following hypotheses:

1.1 Hypotheses

  • H1: Explicit belief management prevents hypothesis lock-in and improves exploration. Tested by Ablation 1 (hypothesis registry with diversification triggers) against Ablation 0 (no belief management).
  • H2: Structured knowledge tracking (KNOWN/UNKNOWN) outperforms hypothesis-confidence tracking. Tested by Ablation 4 (knowledge model) against Ablation 1 (hypothesis registry).
  • H3: Domain-specific prompt content (hints, examples) improves performance. Tested by Ablation 2 (shape hints, worked examples, transfer protocols) against Ablation 1. Also tested by Ablation 5 (efficiency rules, game-over memory) against Ablation 4.
  • H4: Longer action plans improve execution efficiency under time pressure. Tested by Ablation 5 (plans of 8–10 steps when mechanics are known, increased adaptation interval) against Ablation 4 (default 3–5 step plans, interval=10).

2. Experimental Setup

The agent architecture is a loop: observe the game state (a 64×64 pixel grid), analyze it using Python (grid diffs, flood fills, object detection), form a plan, execute actions, and repeat. The backbone model is GPT-5.2. An adaptation cycle runs every N actions (the --interval parameter, default 10), during which the model re-examines the game state and updates its plan.

The puzzle ls20 has at least two levels. Level 1 involves stamp movement, erosion timers, cash-in mechanics, and gate toggling. Level 2 adds tighter time pressure with an approximately 70-action window per attempt. The agent receives 500 total actions and must figure out all mechanics from scratch.

2.1 System Parameters

The agent’s behavior is governed by a small set of tunable parameters, summarized below. These are the independent variables across our ablations; all other aspects of the agent (model, puzzle, observation pipeline) are held constant.

3. Experiments

3.1 Ablation 0: Baseline (no belief management)

No explicit belief management. The agent analyzes the game state and acts based on whatever reasoning emerges naturally in the context window.

Result: 506 actions, score 0, never left Level 1. Four game overs.

The failure mode was hypothesis lock-in, exactly as predicted. The agent committed early to one theory about platform movement and erosion timing, then never explored alternatives. It never discovered the shape-matching mechanic central to ls20. This establishes the baseline against which all subsequent interventions are measured: without structural scaffolding, the model’s default sequential reasoning produces narrative lock-in and exploration failure.

3.2 Ablation 1: Hypothesis registry

We added a structured hypothesis registry. Every analyzer response now includes a [HYPOTHESES] section listing each hypothesis with an ID, confidence score, status, evidence for and against, and a test plan. A HypothesisTracker monitors how long the agent stays on one hypothesis without progress and injects a [HYPOTHESIS DIVERSIFICATION REQUIRED] prompt after 30 stale actions.

Result: 500 actions, score 1. Level 1 completed on the second attempt in 114 actions. Level 2 timed out after 244 actions. One game over. +1 SCORE

This was the first time the agent solved Level 1. It generated 25+ unique hypotheses (vs. 1–2 in baseline) and the diversification trigger fired four times. The agent explored platform movement, click interactions, gate toggles, shape matching, erosion mechanics, cash-in cycles, and n-block clearing before converging on the correct solution path: stamp controls for 5-cell movement, G erosion timer at 2 columns per action, cash-in when G=0, and a $/8 switch toggling remote gates.

Level 2 failed because the agent spent 244 actions re-discovering mechanics and looping between two hypotheses (H3 and H9) without making progress. This motivates H2: perhaps a different representation of the agent’s beliefs would carry knowledge more effectively across levels.

3.3 Ablation 2: Shape analysis hints + cross-level transfer

To help with Level 2, we added domain-specific guidance: a shape analysis section with a Python flood-fill example, a cross-level transfer protocol, and a lower diversification threshold (20 actions instead of 30). This tests H3: whether providing the model with relevant domain knowledge improves its performance.

Result: 500 actions, score 0. Never completed Level 1. Three game overs. REGRESSION

This was worse than both the baseline and Ablation 1. The added prompt complexity caused hypothesis thrashing: 50+ hypothesis switches in 500 actions, constant bouncing between H2, H4, and H5. Game overs came at remarkably consistent intervals—actions 139, 134, and 138—suggesting the agent was reliably failing in the same way each time. It never committed to any hypothesis long enough to actually test it.

This result refutes H3. It confirms something reported in the ARC Prize blog: diminishing and even negative returns from additional hand-engineering. The model performs best with minimal, structural guidance—not domain-specific hints. Prompt complexity is inversely correlated with performance. Structural scaffolding (how to organize thinking) helps; content scaffolding (what to think about) hurts.

3.4 Ablation 3: Minimum commitment constraint (killed early)

We reverted the prompt to the clean Ablation 1 version and added a minimum commitment constraint: block hypothesis switches if the current hypothesis has been active for fewer than 10 actions.

Result: Killed at 154 actions, score 0, still on Level 1. The constraint fired once (blocked a switch at 9 actions, allowed at 12). One diversification trigger.

The constraint reduced thrashing but was insufficient on its own. We terminated the run early to pursue a more fundamental redesign of the belief representation (Ablation 4).

3.5 Ablation 4: Knowledge model

Complete redesign of the belief representation. Instead of tracking hypotheses with confidence scores, the system now tracks knowledge:

  • KNOWN: confirmed mechanics with evidence
  • UNKNOWN: open questions to investigate
  • EXPLORING: which unknown is currently being targeted
  • OBJECTIVE_THEORY: current best theory for how to score

The key design principle: actions always target the most promising unknown. When many things are unknown (early game), exploration is naturally broad. As knowledge grows, the agent narrows focus to remaining unknowns. A KnowledgeTracker maintains a high-water mark—knowledge can only grow—and fires a [STALE EXPLORATION] nudge when no new knowledge is gained for 30 actions. Knowledge carries across game overs.

Result: 500 actions, score 1. Level 1 completed on the first attempt in 49 actions. Level 2 timed out after 451 actions with six game overs. BEST L1

49 actions to solve Level 1 vs. 114 in Ablation 1 and failure in the baseline—a 57% reduction over the best prior result. The human baseline for Level 1 is 21 actions, so the agent is within 2.3x of human efficiency. Knowledge grew steadily from 0 to 4 to 7 known items, and only one stale nudge was needed (vs. four diversification triggers in Ablation 1). This strongly supports H2: knowledge tracking outperforms hypothesis-confidence tracking.

Level 2 remained unsolved but revealed a different bottleneck. Game overs came at strikingly regular intervals: 66, 68, 71, 71, 70, 68 actions. This ~70-action cadence suggests a fixed timer per attempt. The agent knows what to do—it has the mechanics mapped—but cannot execute fast enough. Each analyzer cycle consumes 5–10 actions of overhead, and with only ~70 actions per attempt, that leaves just 7–14 actual decision points. This motivates H4: perhaps longer action plans would improve execution efficiency.

3.6 Ablation 5: Efficiency rules + extended interval

Building on the knowledge model from Ablation 4, we made two changes designed to improve execution efficiency on Level 2. First, we added rules 8–9 to the knowledge model prompt: use longer plans of 8–10 steps when mechanics are known (vs. 2–3 steps during exploration), and inject game-over memory to skip re-exploration of already-known mechanics. Second, we added game-over memory injection to the runner and increased the --interval parameter from 10 to 15, reasoning that fewer adaptation cycles would reduce overhead.

Result: 500 actions, score 0. Never completed Level 1. Three game overs at actions 145, 130, and 132. REGRESSION

A clear regression from Ablation 4, and a second refutation of H3 (adding domain-specific prompt content degrades performance). More importantly, this experiment isolates a critical parameter: the adaptation interval. Increasing --interval from 10 to 15 meant less frequent re-evaluation of the game state, more actions wasted executing stale plans, and fewer opportunities to discover mechanics through observation. The game-over memory and longer plan rules could not compensate for this reduced adaptiveness.

The key lesson: the adaptation interval is a critical parameter. The default interval of 10 with 3–5 step plans is correct. The bottleneck on Level 2 is not plan length but the agent’s ability to quickly converge on the right strategy within the ~70-action window. Longer plans with less frequent re-evaluation make this convergence slower, not faster.

5. Discussion

H1 (belief management) is confirmed. The jump from Ablation 0 to Ablation 1 is the largest single improvement in this study. Without explicit belief management, the model locks into its first plausible narrative and never leaves. A structured registry that forces enumeration of alternatives breaks this default behavior. This is consistent with the broader finding that LLMs require external scaffolding to overcome context-window inertia in sequential reasoning tasks.

H2 (knowledge > hypotheses) is confirmed. Framing the agent’s state as “what do I know and what don’t I know” outperforms “what do I believe and how confident am I.” Hypotheses invite premature commitment to explanations. Knowledge items are monotonic—once confirmed, they stay confirmed—and unknowns give the agent a natural exploration target. This representation reduced Level 1 solve time by 57% and eliminated the need for diversification triggers. The knowledge framing also carries better across game overs, since confirmed facts do not need to be re-derived.

H3 (domain hints help) is refuted twice. Both Ablation 2 and Ablation 5 demonstrate that adding domain-specific content to the prompt degrades performance. In Ablation 2, shape hints and worked examples caused hypothesis thrashing. In Ablation 5, efficiency rules and game-over memory failed to improve on the clean knowledge model. The model has sufficient capability to discover mechanics on its own; overloading the prompt causes interference. We draw a sharp distinction: structural scaffolding (how to organize thinking) helps, while content scaffolding (what to think about) hurts.

H4 (longer plans help) is refuted. Ablation 5 shows that increasing plan length and the adaptation interval actively harms performance. The intuition was that fewer, longer plans would reduce overhead on Level 2. In practice, less frequent adaptation means more actions wasted executing plans based on stale or incorrect beliefs. The bottleneck on Level 2 is not plan length but the speed of strategic convergence within a tight action window. The default interval of 10 with short 3–5 step plans remains the correct configuration.

A recurring theme across all experiments is the importance of parameter sensitivity. The adaptation interval, diversification threshold, and minimum commitment window all have outsized effects relative to the complexity of the prompt content. The most effective interventions are structural and minimal: a knowledge ontology (KNOWN/UNKNOWN/EXPLORING) with a stale-exploration nudge, running at the default interval. Everything else is either neutral or harmful.

6. Conclusion and Future Work

We have shown that an LLM agent playing a procedurally generated game benefits substantially from structured knowledge tracking over hypothesis-confidence tracking, and that explicit belief management of any kind is essential to avoid narrative lock-in. Domain-specific prompt content reliably degrades performance, and the adaptation interval is a more important parameter than plan length.

The remaining bottleneck is Level 2 execution. The agent has the right knowledge but cannot act on it within the ~70-action window. Possible directions include:

  • Adaptive interval: Use a short interval (e.g., 5) during exploration and a longer interval (e.g., 15) only after all mechanics are confirmed as KNOWN, rather than a fixed global parameter.
  • Pre-compiled action sequences: Once a mechanic is confirmed, compile it into a fixed action sequence that executes without re-analysis, reducing per-cycle overhead.
  • Cross-level knowledge seeding: Inject the Level 1 knowledge state directly into the Level 2 prompt, bypassing the re-discovery phase entirely.
  • Multi-puzzle evaluation: All experiments here use a single puzzle (ls20). Validating these findings across a diverse set of ARC-3 puzzles is necessary to establish generality.
